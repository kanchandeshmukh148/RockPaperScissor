# RockPaperScissor
I have created a Rock-Paper-Scissors game using JavaScript, incorporating interactive gameplay with real-time user input and dynamic UI updates. The game allows users to select their move, generates a random choice for the computer, and determines the winner based on the classic rules. It also features score tracking, responsive design, and engaging animations to enhance the user experience.
