A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript. The game allows users to play against the computer with real-time score tracking and instant game results.

---

## 📌 Overview

This project is a browser-based implementation of the classic Rock Paper Scissors game. The computer randomly selects a move, while the user chooses between rock, paper, or scissors. The winner is determined based on the game rules, and the scores are updated automatically.

---

## ✨ Features

- 🎮 Play against the computer
- 🤖 Random computer move generation
- 📊 Live score tracking
- 🏆 Win, lose, and draw detection
- 🎨 Dynamic result messages with color changes
- 🖱️ Interactive click-based gameplay
- 📱 Simple and user-friendly interface

## 🎮 Game Rules

- 🪨 Rock beats Scissors
- 📄 Paper beats Rock
- ✂️ Scissors beat Paper
- If both players choose the same option, the game ends in a draw.
